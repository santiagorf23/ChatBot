¿QUÉ ES ESTE PROYECTO?
-----------------------
Es un chatbot empresarial inteligente que combina:
- Inteligencia Artificial (modelo LLaMA de Groq)
- Procesamiento de documentos (TXT, CSV, PDF)
- Sistema de autenticación con roles (usuarios y administradores)
- Análisis de datos con gráficos
- Predicciones usando Machine Learning

PROPÓSITO:
----------
Permitir que empresas carguen sus documentos de soporte y los usuarios puedan
hacer preguntas que el chatbot responde automáticamente usando IA, reduciendo
la carga de trabajo del equipo de soporte.

B) PROCESAMIENTO DE DOCUMENTOS (Líneas 125-238, 263-315, 317-345)
------------------------------------------------------------------
El sistema puede procesar 3 tipos de archivos:

1. TXT: Texto plano (documentos de soporte, FAQs)
2. CSV: Datos tabulares (ventas, inventarios, estadísticas)
3. PDF: Documentos escaneados o digitales

PROCESO:
1. El archivo se carga en la carpeta uploads/
2. Se lee y convierte a texto
3. Se divide en "chunks" (fragmentos de ~1500 caracteres)
4. Se normaliza el texto (minúsculas, sin acentos)
5. Se vectoriza usando TF-IDF para búsqueda rápida


C) SISTEMA RAG - RETRIEVAL-AUGMENTED GENERATION (Líneas 347-377, 395-424)
--------------------------------------------------------------------------
¡ESTO ES LO MÁS IMPORTANTE!

RAG combina búsqueda + generación de IA:

PASO 1 - BÚSQUEDA (Retrieval):
   Usuario pregunta: "¿Cómo resetear mi contraseña?"
   ↓
   Sistema busca en los chunks del documento los 3 fragmentos más relevantes
   ↓
   Encuentra: Sección de "Recuperación de contraseña"

PASO 2 - GENERACIÓN (Augmented Generation):
   Sistema envía a la IA:
   - Contexto: Los fragmentos relevantes encontrados
   - Pregunta: La pregunta del usuario
   ↓
   IA genera respuesta basada SOLO en el contexto proporcionado
   ↓
   Usuario recibe respuesta precisa y contextualizada

VENTAJAS:
✓ Respuestas basadas en información real de la empresa
✓ No inventa información (reduce "alucinaciones" de la IA)
✓ Más rápido que procesar todo el documento cada vez
✓ Escalable a documentos grandes


D) ANÁLISIS DE DATOS CON IA (Líneas 428-623)
---------------------------------------------
Para archivos CSV, el sistema puede:

1. Responder preguntas sobre los datos:
   - "¿Cuál es el total de ventas?"
   - "¿Cantidad por departamento?"
   - "¿Tendencia por año?"

2. Generar gráficos automáticamente:
   - Gráficos de barras (comparaciones)
   - Gráficos de líneas (tendencias)
   - Gráficos de pastel (distribuciones)

3. PREDICCIONES CON MACHINE LEARNING (Líneas 560-621):
   - Usa regresión polinomial (grado 3)
   - Predice valores futuros basados en tendencias históricas
   - Calcula precisión del modelo (R²)
   - Ejemplo: "Predice ventas para 2025"


E) INTEGRACIÓN CON IA (Líneas 55-86, 381-424)
----------------------------------------------

• Modelo: LLaMA 3.1 8B Instant
• Cliente HTTP personalizado (no requiere SDK oficial)
• Maneja errores y timeouts

def responder_documento(pregunta, chunks_orig, chunks_norm):
    contexto = buscar_contexto(pregunta, chunks_orig, chunks_norm)
    
    mensaje_sistema = f"""Eres un asistente. Responde usando esta información:
    {contexto}
    Si no sabes la respuesta, di que no tienes esa información."""
    
    response = client.chat_completions_create(
        model="llama-3.1-8b-instant",
        messages=[
            {"role": "system", "content": mensaje_sistema},
            {"role": "user", "content": pregunta}
        ]
    )
    return response["choices"][0]["message"]["content"]

                            PREGUNTAS FRECUENTES
═══════════════════════════════════════════════════════════════════════════════

P: ¿Por qué usar RAG en lugar de solo IA?
R: RAG evita que la IA "invente" información. Solo responde basándose en el
   documento real de la empresa, garantizando precisión.

P: ¿Qué pasa si el documento es muy grande?
R: El sistema divide el documento en chunks y solo envía a la IA los fragmentos
   relevantes, haciendo el proceso eficiente incluso con documentos de 1000+ páginas.

P: ¿Se puede usar con otros modelos de IA?
R: Sí, el código es modular. Se puede cambiar Groq por OpenAI, Anthropic, o
   modelos locales como Ollama.

P: ¿Qué tan preciso es el sistema de predicción?
R: Depende de los datos. El modelo calcula R² (coeficiente de determinación).
   R² > 0.8 indica predicciones confiables. R² < 0.5 indica baja confiabilidad.

P: ¿Se pueden cargar múltiples documentos?
R: Actualmente soporta un documento de soporte (usuarios) y un documento de
   análisis (admins). Se puede extender para múltiples documentos.
