1. ACCESO Y CUENTAS
-------------------

¿Cómo crear una cuenta nueva?
Para crear una cuenta en TechCorp Solutions:
1. Visita www.techcorp.com/registro
2. Completa el formulario con tus datos personales
3. Verifica tu correo electrónico (revisa spam si no llega)
4. Activa tu cuenta haciendo clic en el enlace de verificación
5. Inicia sesión con tus credenciales

¿Cómo recuperar mi contraseña?
Si olvidaste tu contraseña:
1. Ve a la página de login (www.techcorp.com/login)
2. Haz clic en "¿Olvidaste tu contraseña?"
3. Ingresa tu correo electrónico registrado
4. Recibirás un enlace de recuperación (válido por 24 horas)
5. Crea una nueva contraseña segura (mínimo 8 caracteres, incluye mayúsculas, 
   números y símbolos)

¿Por qué no puedo iniciar sesión?
Posibles causas:
- Contraseña incorrecta (verifica mayúsculas/minúsculas)
- Cuenta no activada (revisa tu email de verificación)
- Cuenta suspendida por falta de pago
- Navegador con cookies deshabilitadas
- Conexión a internet inestable

Solución: Intenta recuperar tu contraseña o contacta a soporte@techcorp.com

4. PROBLEMAS TÉCNICOS COMUNES
------------------------------

El sistema está muy lento
Soluciones:
1. Limpia el caché de tu navegador
2. Cierra pestañas innecesarias
3. Verifica tu conexión a internet (mínimo 5 Mbps recomendado)
4. Prueba en modo incógnito
5. Actualiza tu navegador a la última versión
6. Si persiste, contacta a soporte con tu ID de sesión

Error al cargar archivos
Verifica que:
- El archivo no supere 100MB
- El formato sea compatible (PDF, CSV, TXT, XLSX, JSON)
- Tu plan incluya almacenamiento suficiente
- No uses caracteres especiales en el nombre del archivo
- Tu conexión sea estable durante la carga

No recibo notificaciones por email
Soluciones:
1. Revisa tu carpeta de spam/correo no deseado
2. Agrega soporte@techcorp.com a tus contactos
3. Verifica la configuración de notificaciones en tu cuenta
4. Confirma que tu email esté correctamente escrito
5. Revisa que tu bandeja de entrada no esté llena

Error "Sesión expirada"
Esto ocurre cuando:
- Has estado inactivo por más de 2 horas
- Iniciaste sesión en otro dispositivo
- Cambiaste tu contraseña recientemente

Solución: Simplemente vuelve a iniciar sesión.


5. INTEGRACIONES Y API
-----------------------

¿Cómo integrar TechCorp con otras aplicaciones?
Ofrecemos:
- API REST completa (documentación en developers.techcorp.com)
- Webhooks para eventos en tiempo real
- Conectores nativos para: Salesforce, HubSpot, Slack, Microsoft Teams, 
  Google Workspace, Zapier, Make (Integromat)
- SDK disponibles en: Python, JavaScript, Java, PHP, Ruby

¿Dónde obtengo mi API Key?
1. Inicia sesión en tu cuenta
2. Ve a "Configuración" → "API & Integraciones"
3. Haz clic en "Generar Nueva API Key"
4. Copia y guarda tu clave de forma segura (solo se muestra una vez)
5. Usa la clave en el header: Authorization: Bearer TU_API_KEY

Límites de la API:
- Plan Básico: 1,000 requests/hora
- Plan Profesional: 10,000 requests/hora
- Plan Empresarial: 100,000 requests/hora
- Límite de tasa: 100 requests/minuto


6. SEGURIDAD Y PRIVACIDAD
--------------------------

¿Mis datos están seguros?
Sí, implementamos:
- Encriptación SSL/TLS en todas las comunicaciones
- Encriptación AES-256 para datos en reposo
- Autenticación de dos factores (2FA) disponible
- Backups automáticos diarios
- Servidores en centros de datos certificados ISO 27001
- Cumplimiento con GDPR, CCPA y leyes de protección de datos

¿Cómo habilitar autenticación de dos factores (2FA)?
1. Ve a "Mi Cuenta" → "Seguridad"
2. Haz clic en "Habilitar 2FA"
3. Escanea el código QR con Google Authenticator o Authy
4. Ingresa el código de 6 dígitos para confirmar
5. Guarda los códigos de recuperación en un lugar seguro

¿Quién tiene acceso a mis datos?
- Solo tú y los usuarios que autorices en tu cuenta
- Personal de soporte técnico (solo con tu permiso explícito)
- Nunca vendemos ni compartimos tus datos con terceros
- Puedes exportar o eliminar tus datos en cualquier momento

                              SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: No puedo cargar archivos grandes
SOLUCIÓN: 
- Límite actual: 100MB por archivo
- Para archivos más grandes, usa nuestra API de carga por chunks
- O contacta a ventas para aumentar tu límite

PROBLEMA: Dashboard no muestra datos actualizados
SOLUCIÓN:
- Presiona Ctrl+F5 para refrescar forzadamente
- Verifica que los datos se hayan sincronizado correctamente
- Revisa la última fecha de actualización en el footer del dashboard

PROBLEMA: Error "Límite de API excedido"
SOLUCIÓN:
- Has alcanzado el límite de requests de tu plan
- Espera a que se reinicie el contador (cada hora)
- O actualiza a un plan superior

PROBLEMA: No puedo invitar a miembros del equipo
SOLUCIÓN:
- Verifica que tu plan incluya usuarios múltiples
- Plan Básico: 1 usuario
- Plan Profesional: hasta 5 usuarios
- Plan Empresarial: usuarios ilimitados
